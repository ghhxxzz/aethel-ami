# Guia de instalação

## Para desenvolver (no seu computador)

Instale, nesta ordem, e **reabra o terminal** depois de cada um:

1. **Node.js (LTS)**: nodejs.org
2. **Git**: git-scm.com
3. **Rust**: rustup.rs (só é necessário para gerar o `.exe`)
4. **Build Tools do Visual Studio** com "Desenvolvimento para desktop com C++" (só para gerar o `.exe`)

Confira:

```
node -v
npm -v
git --version
rustc --version
```

Depois siga o `README.md` (backend e app). Use um terminal comum, **não** como administrador.

## Para usar o app instalado (usuário final)

O instalador `Aethel-AMI-Setup.exe` ainda **não foi gerado**. Quando for, esta seção terá o passo a passo de instalação e o que fazer se o Windows exibir o aviso do SmartScreen.
